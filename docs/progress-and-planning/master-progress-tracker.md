# Master Progress Tracker (ssc-mobile)

**Status:** Phase 2 (Authentication & Secure Storage)

This repository (`ssc-mobile`) is a high-performance React Native (CLI) application that serves as the mobile equivalent to the `ssc-client` web application. It consumes the `ssc-api` backend.

## Roadmap

- **Phase 1: Foundation (Completed)** - Scaffolded React Native CLI, configured NativeWind, React Navigation, React Query, Reanimated, FlashList, Axios interceptors.
- **Phase 2: Auth (Current)** - JWT, secure storage (react-native-keychain), Zustand auth store, Login & Registration UI.
- **Phase 3: Dashboard** - Consuming subjects and chapters APIs.
- **Phase 4: Practice Engine** - Native quiz UI.
- **Phase 5: Store** - Native gamification store.

## Current Context
- Executing Phase 2: Implementing `useAuthStore` and building out the authentication screens.
